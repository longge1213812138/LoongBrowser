# 玻璃不染色，用高光与圆角承担 Vista 辨识度

实测确认 DWM 的 Acrylic 只接受系统主题的亮/暗一个维度，没有 alpha 或色相旋钮。因此放弃给玻璃染色，改为在自绘外壳上复刻 Vista 的辨识元素：顶部 1px 白色高光、底部 1px 深色阴影、8px 圆角，冷蓝 `#A0C8F0` 只用于选中标签与描边等非玻璃元素。

## 考虑过的替代方案

- **跟随系统主题，完全不干预**：玻璃颜色不可控，用户在浅色系统下拿不到深色浏览器。
- **DWM 提供基础模糊 + 自绘半透明染色层**：叠加层与真实模糊互相削弱，两边都不讨好。

## 后果

玻璃的观感随用户系统主题变化，浏览器不保证固定的 Vista 配色。Vista 的视觉特征由 `GlassChrome` 的自绘层承担，而非玻璃层本身。
